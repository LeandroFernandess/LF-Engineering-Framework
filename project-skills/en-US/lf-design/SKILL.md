# LF Design

1. Read the project instructions, `.ai/contracts.md` and applicable design artifacts. Locate the versioned Framework source from `LF_ENGINEERING.md`; consult `knowledge/INDEX.md` and `knowledge/REGISTRY.md`.
2. Preserve existing approved tokens and specified palettes; otherwise apply the LF default palette for visual interfaces. Use `knowledge/ENGINEERING_DESIGN_PERFORMANCE.md` for responsive behavior, accessibility and performance.
3. Load `knowledge/ENGINEERING_MOTION_DESIGN.md` when motion is in scope. Select only relevant interaction and device guidance; do not add motion, dependencies or a new phase by default.
4. Use the Design System Analyst and `docs/DESIGN.md` when their existing conditions apply. Keep observed references, proposed directions and approval distinct. Follow the approved plan and project boundaries.
5. For review, inspect representative states and inputs, keyboard and touch behavior, contrast and relevant mobile/desktop profiles. Report evidence and unverified behavior; do not claim device validation from emulation alone.
