# LF Delivery Review

1. Compare the implementation and diff with the approved plan, acceptance
   criteria, project contracts and current `.ai/state/`.
2. Use the official Framework source identified in `LF_ENGINEERING.md`. When
   the canonical repository is available, consult `knowledge/INDEX.md`,
   `knowledge/REGISTRY.md`, the applicable workflow and canonical reviewer,
   QA-Security, Documentation and Tech Lead definitions.
3. Check correctness, regressions, trust boundaries, user-visible behavior,
   required artifacts and verification evidence. Apply conditional reviews only
   when their stated conditions apply.
4. Record findings, evidence, unresolved risks and delivery readiness in the
   project's prescribed artifacts. Keep the external Framework read-only.

Do not claim a gate passed without evidence or replace the user's manual
validation when the workflow requires it.
