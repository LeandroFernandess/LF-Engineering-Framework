# LF Approved Implementation

1. Re-read the approved plan, project instructions, applicable contracts and
   current `.ai/state/`. Use the official Framework source identified in
   `LF_ENGINEERING.md`.
2. Follow the approved scope and acceptance criteria. Consult the applicable
   workflow and only the canonical agents, knowledge and protocols it requires.
3. Keep edits inside the client project. Preserve existing files and decisions;
   update the relevant `.ai/` and `.ai/state/` records as work progresses.
4. Run the verification named by the approved plan when authorized. Report
   evidence and any unverified criteria accurately.

Do not revise the plan's scope or edit the external Framework library without
separate approval. Route a material scope, architecture or risk change back for
review before proceeding with dependent work.
