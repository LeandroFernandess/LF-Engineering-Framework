# EN-US Source Index

EN-US is the technical source language and default bootstrap language. Canonical
technical documentation and the neutral `PROJECT_TEMPLATE/` remain at the
repository root; this directory is an index, not a duplicated EN-US source tree.

PT-BR mirrors and translated public documents are grouped under
[`../pt-BR/`](../pt-BR/), with coverage recorded in
[`../pt-BR/TRANSLATION_STATUS.md`](../pt-BR/TRANSLATION_STATUS.md).

Use `--language en-US` explicitly when the selected language should be recorded
in the project installation metadata.
