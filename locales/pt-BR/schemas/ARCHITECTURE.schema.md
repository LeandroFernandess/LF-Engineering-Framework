# Schema de arquitetura

## Objetivo

Estrutura canônica para documentos de arquitetura produzidos pelo Software
Architect Agent.

## Seções obrigatórias

- Visão geral da arquitetura
- Contexto e restrições
- Componentes do sistema
- Modelo de dados
- Integrações
- Modelo de segurança
- Considerações de performance
- Considerações operacionais
- Decisões principais
- Riscos e trade-offs
- Estratégia de validação
- Notas de handoff

## Validação

- A arquitetura deve satisfazer as restrições do PRD.
- As decisões devem ser explícitas e rastreáveis.
- Os riscos devem incluir uma rota de mitigação ou escalonamento.
- Decisões significativas devem ser refletidas em `ADR.md`.
