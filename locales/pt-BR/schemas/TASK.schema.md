# Schema de tarefa

## Objetivo

Estrutura canônica para tarefas executáveis de engenharia.

## Campos obrigatórios

- ID
- Título
- Objetivo
- Contexto
- Entradas
- Saída esperada
- Critérios de aceite
- Dependências
- Riscos
- Status
- Notas de handoff

## Valores de status

- Backlog
- Pronta
- Em andamento
- Bloqueada
- Em revisão
- Concluída
