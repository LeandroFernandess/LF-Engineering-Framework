# Schema de ADR

## Objetivo

Estrutura canônica para registros de decisões arquiteturais.

## Seções obrigatórias

- Título
- Status
- Data
- Contexto
- Decisão
- Alternativas consideradas
- Consequências
- Artefatos relacionados

## Valores de status

- Proposta
- Aceita
- Substituída
- Rejeitada
