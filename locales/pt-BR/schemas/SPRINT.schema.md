# Schema de sprint

## Objetivo

Estrutura canônica para planejamento de sprint produzido pelo Sprint Planner
Agent.

## Seções obrigatórias

- Objetivo da sprint
- Escopo
- Tarefas
- Dependências
- Critérios de aceite
- Plano de validação
- Riscos
- Fora de escopo
- Notas de handoff

## Campos das tarefas

- ID
- Título
- Descrição
- Agente responsável
- Dependências
- Critérios de aceite
- Status
