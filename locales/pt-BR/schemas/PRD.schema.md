# Schema de PRD

## Objetivo

Estrutura canônica para documentos de requisitos de produto produzidos pelo
Product Owner Agent.

## Seções obrigatórias

- Visão geral do produto
- Declaração do problema
- Metas
- Não objetivos
- Usuários e stakeholders
- Requisitos funcionais
- Requisitos não funcionais
- Escopo do MVP
- Critérios de aceite
- Riscos e premissas
- Questões abertas
- Notas de handoff

## Validação

- Os requisitos devem ser testáveis.
- As fronteiras do MVP devem ser explícitas.
- As premissas devem ser identificadas.
- Detalhes de implementação técnica devem ser adiados para
  `ARCHITECTURE.md`.
- Quando pesquisa com usuários informar uma decisão de produto, referencie seu
  método, data, escopo das evidências e limitações nas seções relevantes do PRD.
  Não inclua dados identificáveis de participantes nem apresente respostas
  sintéticas como evidência de participantes; um artefato de pesquisa separado
  não é exigido por padrão.
