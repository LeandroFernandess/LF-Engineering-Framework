# Registro de agentes de engenharia LF

Versão: 1.5.0

Status: Estável

---

## Objetivo

Este registro mapeia cada agente do LF Engineering System para seu papel
operacional, entradas esperadas, artefatos produzidos, arquivos de Knowledge
recomendados, workflows relacionados e provável próximo agente.

Use este arquivo antes de selecionar agentes ou etapas de workflow. Ele
complementa a documentação canônica dos agentes em `agents/` e o mapa de
interação em `agents/AGENT_INTERACTION_MAP.md`.

## Regras de seleção

- Verifique `.ai/contracts.md` antes de encaminhar o trabalho para confirmar que
  os artefatos upstream necessários existem ou que dependências ausentes foram
  explicitamente aceitas.
- Use Engineering-Manager antes de Orchestrator para intake de demanda bruta e
  geração de `MANAGER_BRIEF`.
- Use o Registry para seleção de agentes e `agents/<Agent>/` para o comportamento
  canônico do agente selecionado.
- Use `agents/AGENT_INTERACTION_MAP.md` quando a ordem do handoff não estiver
  clara.
- Não adicione novos agentes somente a partir deste registro; novos agentes
  exigem documentação canônica própria em `agents/`.
