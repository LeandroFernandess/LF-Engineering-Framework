# Pacote de idioma PT-BR

PT-BR contém o template de projeto traduzido, espelhos dos módulos técnicos e
documentos públicos traduzidos. A fonte canônica EN-US dos módulos técnicos
continua na raiz do repositório. Os documentos públicos PT-BR ficam em
`public-docs/` e o espelho do ADR em `docs/`.

Use `--language pt-BR` para instalar o template de projeto em português e
registrar essa escolha em `.ai/framework-installation.md`.
