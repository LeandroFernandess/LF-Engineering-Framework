# Planejamento de projeto LF

1. Leia as instruções do projeto, `.ai/contracts.md` e o estado atual em
   `.ai/state/`. Use a fonte oficial do Framework identificada em
   `LF_ENGINEERING.md`.
2. Quando o repositório canônico estiver disponível, consulte
   `knowledge/INDEX.md`, `knowledge/REGISTRY.md` e o workflow aplicável antes
   de carregar definições de agentes.
3. Confira os artefatos upstream exigidos e registre entradas ausentes ou
   exceções aceitas. Selecione apenas agentes, módulos e protocolos relevantes.
4. Defina arquivos afetados, comportamento, critérios de aceite, verificações,
   riscos e exclusões. Inclua artefatos condicionais apenas quando aplicáveis.
5. Apresente o plano para aprovação antes de implementar. Não infira aprovação
   de um rascunho, lista de tarefas ou aprovação anterior sem relação com o plano.

Use `workflows/NEW_PROJECT.md` para inicialização e
`workflows/STANDARD_DEVELOPMENT.md` para mudanças em projetos existentes.
Mantenha o conteúdo canônico do Framework externo e somente para leitura.
