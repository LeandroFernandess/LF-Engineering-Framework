# Integração inicial de projeto LF

1. Leia as instruções do projeto e `.ai/contracts.md`, quando existir. Use a
   fonte oficial do Framework identificada em `LF_ENGINEERING.md`.
2. Mantenha o Framework somente para leitura. Quando o repositório canônico
   estiver disponível, consulte `knowledge/INDEX.md` e `knowledge/REGISTRY.md`
   antes de selecionar conhecimento ou agentes.
3. Siga `workflows/NEW_PROJECT.md` e as definições canônicas dos agentes
   relevantes quando estiverem acessíveis. Carregue apenas os módulos e
   artefatos necessários e informe quando alguma fonte não puder ser acessada.
4. Confira os arquivos exigidos e `.ai/state/` conforme o workflow e os
   contratos. Registre exceções aceitas no arquivo de decisões do projeto.

Não copie as pastas completas `agents/`, `knowledge/`, `workflows/`,
`protocols/` ou `schemas/` para o projeto cliente. O registro de instalação
identifica a fonte e a versão do Framework, sem armazenar uma localização local.
