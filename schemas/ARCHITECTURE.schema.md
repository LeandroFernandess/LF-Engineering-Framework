# Architecture Schema

## Purpose

Canonical structure for architecture documents produced by the Software Architect Agent.

## Required Sections

- Architecture Overview
- Context and Constraints
- System Components
- Data Model
- Integrations
- Security Model
- Performance Considerations
- Operational Considerations
- Key Decisions
- Risks and Trade-Offs
- Validation Strategy
- Handoff Notes

## Validation

- Architecture must satisfy the PRD constraints.
- Decisions must be explicit and traceable.
- Risks must include mitigation or escalation path.
- Significant decisions should be mirrored in `ADR.md`.
