# Sprint Schema

## Purpose

Canonical structure for sprint planning produced by the Sprint Planner Agent.

## Required Sections

- Sprint Goal
- Scope
- Tasks
- Dependencies
- Acceptance Criteria
- Validation Plan
- Risks
- Out of Scope
- Handoff Notes

## Task Fields

- ID
- Title
- Description
- Owner or Responsible Agent
- Dependencies
- Acceptance Criteria
- Status
