# LF Engineering Agent Registry

Version: 1.5.0

Status: Stable

---

## Purpose

This registry maps each LF Engineering System agent to its operational role, expected inputs, produced artifacts, recommended knowledge files, related workflows and likely next agent.

Use this file before selecting agents or workflow steps. It complements the canonical agent documentation in `agents/` and the interaction map in `agents/AGENT_INTERACTION_MAP.md`.

## Selection Rules

- Check `.ai/contracts.md` before routing work to confirm that required upstream artifacts exist or that missing dependencies are explicitly accepted.
- Use Engineering-Manager before Orchestrator for raw user demand intake and `MANAGER_BRIEF` generation.
- Use the Registry for agent selection and `agents/<Agent>/` for the canonical behavior of the selected agent.
- Use `agents/AGENT_INTERACTION_MAP.md` when the handoff order is unclear.
- Do not add new agents from this registry alone; new agents require their own canonical documentation under `agents/`.
