# Bilingual terminology / Terminologia bilíngue

EN-US is the canonical technical language; PT-BR mirrors translate prose without
changing paths, command options, placeholders or contract identifiers.
EN-US é o idioma técnico canônico; os espelhos PT-BR traduzem a prosa sem alterar
caminhos, opções de comandos, placeholders ou identificadores de contrato.

| EN-US | PT-BR | Usage / Uso |
| --- | --- | --- |
| setup assistant | assistente de instalação | Interactive entrypoint / Entrada interativa |
| bootstrap | bootstrap | Native automation command / Comando nativo de automação |
| preview / dry-run | prévia / dry-run | No project writes / Sem escrita no projeto |
| apply | aplicar | Copy missing files and restrict state access / Copiar ausentes e restringir acesso ao estado |
| adapter / integration | adapter / integração | Keep CLI values unchanged / Preservar valores do CLI |
| workflow | workflow | Established technical term / Termo técnico estabelecido |
| handoff | handoff | Transfer of responsibility / Transferência de responsabilidade |
| acceptance criteria | critérios de aceite | Observable completion conditions / Condições observáveis de conclusão |
| canonical source | fonte canônica | Normative root document / Documento normativo na raiz |
| translation mirror | espelho traduzido | Corresponding PT-BR document / Documento PT-BR correspondente |
| owner | responsável | Person accountable for follow-up / Pessoa responsável pelo acompanhamento |
| approved optional | opcional aprovado | Does not authorize installation / Não autoriza instalação |
| finding | achado | Evidence-backed review result / Resultado de revisão com evidência |
| not verified | não verificado | Missing evidence, not approval / Evidência ausente, não aprovação |
| static fallback | fallback estático | Preserve the mark when animation or terminal control is unavailable / Preservar a marca sem animação ou controle do terminal |

`MANAGER_BRIEF`, `PROCEED`, `NEEDS_CLARIFICATION`, work-type enums, file names,
`RF-001`/`RNF-001`, and installation-record keys (`Language`, `Adapter`,
`Framework source`, `Framework`) remain stable in both languages. Human-facing
status labels may be translated; identifiers consumed by tools must not be.

`MANAGER_BRIEF`, `PROCEED`, `NEEDS_CLARIFICATION`, enums de tipo de trabalho,
nomes de arquivos, `RF-001`/`RNF-001` e chaves do registro de instalação
(`Language`, `Adapter`, `Framework source`, `Framework`) permanecem estáveis.
Rótulos de status para leitura humana podem ser traduzidos; identificadores
consumidos por ferramentas não devem ser alterados.
